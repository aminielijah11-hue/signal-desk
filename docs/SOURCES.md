## Findings that changed from the PROMPT.md spec

1. **House mirror repo moved.** `timothycarambat/house-stock-watcher-data`
   (the repo named in PROMPT.md §3.2) returns `404` — it no longer exists
   under that owner. Found `TattooedHead/house-stock-watcher-data` as an
   actively-maintained successor (pushed within 24h of this recon, not a
   GitHub fork, same `data/all_transactions.json` layout). Using this as
   the House mirror source for Phase 5. The Senate mirror
   (`timothycarambat/senate-stock-watcher-data`) is unchanged and still
   live. **Risk:** a community-maintained mirror can disappear again;
   Phase 5's `source_disagreement` logging must not treat mirror silence
   as ground truth, and House disagreement checks should degrade
   gracefully (log + flag, don't block) if this mirror goes dark too.

2. **SEC daily-index probe must target the last published weekday, not
   "today."** Today's `.idx` file returned `403` in the first recon pass
   simply because it isn't published yet at time of day — not a dead
   endpoint. The script now probes the most recent completed weekday.
   Note for Phase 4: the real ingester must handle "not yet published"
   as a normal, expected, retryable state, not an error.

3. **FRED CSV vs JSON.** The plain CSV graph endpoint
   (`fred.stlouisfed.org/graph/fredgraph.csv?id=SERIES`) works with no key
   and is enough for the four series needed (§3.4: DGS10, T10Y2Y, VIXCLS,
   a financial-conditions index). The full FRED JSON API needs a free key
   (instant signup, no approval wait) — listed in the accounts section.
   Recommendation: use the CSV endpoint for Phase 7 and skip the JSON API
   key entirely unless a series isn't available via CSV. Saves one account
   signup.

4. **Added Stooq as a second free EOD cross-check candidate** alongside
   `yfinance` (unofficial, can break) and Tiingo/Alpaca (need a free key).
   Stooq has no documented rate policy — same "wrap it, be resilient"
   treatment as yfinance, not a primary source.
